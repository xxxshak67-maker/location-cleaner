# location-cleaner

中文地名脏数据清洗工具：读取 Excel 第一列的地名，自动拆分、去重，并借助 [cpca](https://github.com/DQinYuan/chinese_province_city_area_mapper) 标准化为 **「省 + 市」** 格式，同时识别不合规数据与疑似多地名粘连数据，便于人工二次处理。

## 功能特性

- **自动拆分多地名**：按 `，` `,` `、` `；` `;` `:` `：` `.` 空格、全角空格，以及 `+` `/` `\` `|` `-` 和连接词「**及**」「**和**」「**与**」拆分，一行可拆成多行独立分析对象。
- **格式清洗**：去首尾空白（含全角空格）、删除阿拉伯数字（含全角数字）、英文字母统一转大写。
- **标准化转换**：基于 cpca 把地名规范为「xx省xx市」格式；支持裸区县名后缀回退（如 `双流` → `四川省成都市`）。
- **粘连贪心解析**：对「只匹配到局部 / 多地名粘连」的文本（如 `常州苏州杭州`、`常州市苏州市`），先尝试**贪心逐段拆分**为多个成功行；全部拆不开时才标为**处理失败**，交由人工，绝不输出半截结果。
- **问题数据分离**：输出——成功 / 不合规 / 处理失败，并标注问题类型；对拆不动的粘连数据自动标注「**应删除**」，便于人工判断。

## 输出格式

例如源数据`dirty_data.xlsx`为:

| 成都，西安 |
|---|
| 常州苏州杭州 |
| 南方公园 |
| 成都&其他 |


生成 `result.xlsx`，六列：

| 源数据 | 拆分片段 | 处理后数据 | 剩余问题数据 | 问题类型 | 应删除 |
|--------|----------|------------|--------------|----------|--------|
| 成都，西安 | 成都 | 四川省成都市 | | | |
| 常州苏州杭州 | 常州 | 江苏省常州市 | | | |
| 常州苏州杭州 | 苏州 | 江苏省苏州市 | | | |
| 常州苏州杭州 | 杭州 | 浙江省杭州市 | | | |
| 成都，西安 | 西安 | 陕西省西安市 | | | |
| 南方公园 | 南方公园 | | 南方公园 | 不合规 | |
| 成都&其他 | 成都&其他 | | 成都&其他 | 处理失败 | 是 |

- **处理后数据**：识别成功的标准地名（按「省+市」排序，排在最前）。
- **剩余问题数据 / 问题类型**：`不合规`（POI、带「等/等等」、完全无法识别）或 `处理失败`（疑似多地名粘连，交人工拆分）。
- **应删除**：仅对「粘连拆不动」且「首个有效城市之后的剩余文本长度 ≥ 2」的问题数据标注 `是`，提示人工可直接删除。
- 同一句源数据拆成多段时，源数据列重复写整句，可对应多行结果；粘连文本被贪心拆开时也会产生多行成功结果。

## 安装

```bash
pip install pandas openpyxl tqdm cpca
```

> 需 Python 3.9+（建议 3.10+）。`cpca` 建议 0.5.5 及以上。

## 使用

1. 准备输入 Excel（如 `dirty_data.xlsx`），**第一列为地名脏数据**。
2. 在 `location_cleaner.py` 顶部按需修改配置：

   ```python
   INPUT_FILE   = r"./examples/dirty_data.xlsx"   # 输入文件
   OUTPUT_FILE  = r"./examples/result.xlsx"       # 输出文件
   SHEET_NAME   = 0                    # 读取的工作表
   CPCA_BATCH_SIZE  = 200              # cpca 分批大小
   RESIDUAL_THRESHOLD = 2              # 粘连检测残留阈值
   ```

3. 运行：

   ```bash
   python location_cleaner.py
   ```

4. 完成后查看 `result.xlsx` 与终端统计（总数 / 成功数 / 不合规数 / 处理失败数）。

## 处理规则速览

| 输入 | 结果 | 说明 |
|------|------|------|
| `赣州` | `江西省赣州市` | 只识省/市，自动补全 |
| ` 四川省成都市 ` | `四川省成都市` | 去首尾空白 |
| `双流1` / `双流１` | `四川省成都市` | 去数字 + 裸区县后缀回退 |
| `成都，乐山` | `四川省成都市` / `四川省乐山市` | 逗号拆分，一行变多行 |
| `成都，广东。` | `四川省成都市` / `广东省` | 句号只剥离、不作分隔 |
| `成都及乐山` | `四川省成都市` / `四川省乐山市` | 连接词「及/和/与」可拆分 |
| `贵州等` | 不合规 | 含「等/等等」 |
| `常州苏州杭州` | `江苏省常州市` / `江苏省苏州市` / `浙江省杭州市` | 粘连 → 贪心逐段拆开 |
| `眉山青白江及什邡` | 处理失败（应删除=是） | 粘连但部分解不动，交人工 |
| `交子公园` | 不合规 | POI，无法识别 |

## 注意事项

- **连接词误拆**：拆分使用了「和」字作为分隔符，因此含「和」的真实地名（如 `和田` `呼和浩特`）会被误拆。如数据中含此类地名，请人工审查。
- **粘连解析**：贪心策略从左向右逐段消费「最短可解析地名」，并清理孤立后缀字（如「常州市苏州市」消费「常州」后去掉残留的「市」）。多数粘连可自动拆开；解不动的部分标为处理失败并提示「应删除」。
